CAGLIARI DERIVED NETWORK DATA OFFER

network.net.xml is the complete machine-readable SUMO network database used by every one of the 35 cases (210 controller simulations) in the frozen Step 09 evaluation. It is an exact byte copy: no numerical content, identifiers, attributes, geometry, comments or headers were removed or rewritten for publication. The inspected source already had no XML comments, private machine paths or original contributor account metadata. Geographic coordinates, road/edge identifiers and the experimental signal plan are intentionally retained in this data download; the visible replay does not display a geographic map.

The source was a stored OpenStreetMap extract of Cagliari. Its SHA-256 is 981435c9e6103e3aa3e864e3b43bdcf4167da9232b2e28b71e4515544d2cb4b4. The exact original download date/API request is not known; no current map link is presented as the original input. The derived database, rather than an alteration algorithm or the original extract, is supplied here.

The transformation used SUMO 1.15.0 / Debian 1.15.0+dfsg-1+deb12u1, with an experimental aggregation of junction nodes, a retained boundary, inferred sidewalks/crossings and protected signal stages. Entire intersecting edges are retained, so the boundary is not an exact geometric clip. These are experimental data, not validated city infrastructure or road-operation instructions.

Embedded type-map-derived definitions have separate SUMO content provenance. Their exact unmodified source, Debian copyright/EPL-2.0 text and versioned upstream notice are included in ../licenses/. See ../NOTICE.txt. The network's ODbL database designation does not remove those component terms.

The selected traces and summary measurements are synthetic simulation observations. They are not OSM contributor measurements. No map tiles, raw contributor histories, model checkpoints, simulator executable or full historical repository source are included in this offer.
